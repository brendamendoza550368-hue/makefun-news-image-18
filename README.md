One image that sums up the world news of **Wednesday 18 November 2026**: the Gulf escalation (US strikes on Iran's Qeshm Island, Iran hitting back at Bahrain and Kuwait), Xi Jinping and Vladimir Putin meeting in Shenzhen ahead of their three-way summit with Donald Trump, Ukraine striking the Crimea Bridge for a second day and dropping a span into the strait, Democrats sealing a 56-44 Senate majority with the Alaska win, the Congo Ebola outbreak passing 11,000 cases, and Voyager 1 reaching one light-day from Earth.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program copies `entry.png` byte for byte into the output directory and verifies the copy — the picture is the entry, drawn as six captioned panels under the day's date.
